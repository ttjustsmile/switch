# assets

**这个目录是空的，仓库里不含任何图片。**

壁纸素材版权情况各不相同，不适合跟代码一起分发。请只使用你自己拥有或已获授权的素材。

## 放这里

把壁纸命名成 `wall-1.jpg`、`wall-2.jpg`… 放进这个目录，然后：

**web** — 改 `web/switch.js` 和 `web/switch-boot.js` 里的 `WALLS`（两处都要改，引导脚本必须内联所以引用不到 switch.js）：

```js
var WALLS = ['assets/wall-1.jpg?v=1', 'assets/wall-2.jpg?v=1'];
var THEMES = ['light', 'dark'];   // 每张图配浅色还是深色主题
```

⚠️ 路径后面那个 `?v=1` 不是摆设。改图但不改文件名时，浏览器缓存和 Service Worker 里的旧图会一直顶着，怎么刷新都是老的。**换图记得把版本号 +1。**

**iOS** — 图不放这儿，拖进 `Assets.xcassets`，名字写进 `Theme.walls`。

## 挑图的两条经验

**整套要么都浅要么都深，别混着还标同一个主题。** `THEMES` 那个数组就是干这个的 —— 标错了会出现深色壁纸配浅色字，一片糊。

**碎花、密集纹理这类图，上面的卡片一律不透明。** 半透明卡片 + 碎花底会把字搅得完全读不了；毛玻璃在这种图案上也只是把它糊成一团脏色。要通透感就调卡片本身的颜色，别开滤镜。
